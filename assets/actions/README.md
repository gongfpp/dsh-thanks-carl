# 卡尔 AI 动作素材

十二组动作由用户提供并确认用于此插件：待机、招手、摸摸、害羞、瞌睡、庆祝、走路、翻滚、受惊、兴奋、炸毛、肚皮朝上。它们是 AI 生成的角色动作，不是原始 Carl 照片的连拍；具体生成模型未经核实。

本地处理从 PNG 精灵表切帧，移除背景、去除绿溢色，并固定角色水平中心与脚底锚点。白底待机使用已批准的招手轮廓作为内部抠图参考，保护白色毛发；不替换角色 RGB 为其他动作。每组保留16个源帧，单帧192×144，横排为3072×144的透明 WebP。

运行时在本地精灵表上逐帧播放并正放后倒放收尾，避免首尾硬切；不调用模型、远程生成服务或加载第三方图片。十二张精灵表已内嵌进构建后的客户端，npm 不重复分发一套二进制；此目录源图用于仓库构建。

本批动作基于 Carl 形象生成；代码 MIT 许可不授予照片或衍生形象的额外权利，素材仅随本插件用于个人、非商业用途，权利人异议时移除。原照片出处与核实限制见仓库 docs/technical-decisions.md。

设置可以关闭 AI 动作并恢复原梗图。用户自定义照片、系统减少动态效果下不以 AI 形象替换图片。夸张动作只经用户手动选择播放，不代表真实任务失败或危险。
